# prime

This workspace is the management plane: the work itself happens in other workspaces, and this one is where you plan it, start it and follow it.
The operator keeps one ledger file per task under `tasks/` in this workspace, with the goal, where the work runs and what has happened so far. An agent whose own role says it never writes files leaves the ledger to the operator.
When you are unsure how to do something on this platform, read the platform wiki first.
